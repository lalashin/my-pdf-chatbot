# [Plan] pdf-chatbot

## Executive Summary

| 관점 | 내용 |
|------|------|
| **Problem** | 업무 담당자가 PDF 문서(예: 근로기준법)에서 원하는 정보를 직접 찾아야 해 시간이 많이 걸리고, AI 답변이 문서 외 내용을 지어내는 할루시네이션 위험이 있다. |
| **Solution** | PDF 텍스트를 추출해 Claude AI 컨텍스트로 전달하고, 문서 내용에만 근거한 답변을 강제하는 시스템 프롬프트로 신뢰할 수 있는 FAQ 챗봇을 구축한다. |
| **Function UX Effect** | 질문 입력 → 말풍선 형태의 즉시 답변으로 문서 탐색 시간을 없애고, `docs/` 폴더의 PDF만 교체하면 어떤 문서에도 적용 가능하다. |
| **Core Value** | API 키를 Vercel 서버리스에서만 처리하는 보안 구조로, 누구나 자신의 PDF로 교체해 바로 배포할 수 있는 노무 FAQ 챗봇 템플릿이다. |

---

## 1. 기능 개요

- **기능명**: PDF 기반 노무 FAQ 챗봇 (pdf-chatbot)
- **작성일**: 2026-05-04
- **레벨**: Dynamic (Node.js + Express → Vercel 서버리스)

## 2. 목적 및 배경

업무 현장에서 근로기준법 등 PDF 형태의 법령·지침 문서를 참고할 때, 원하는 내용을 직접 찾는 데 시간이 소요된다. 또한 일반 AI 챗봇은 문서에 없는 내용을 지어내는 할루시네이션 문제가 있어 업무 신뢰성이 떨어진다.

이 챗봇은 **PDF 내용에만 근거한 답변**을 강제하여 신뢰성을 확보하고, `docs/` 폴더의 PDF를 교체하는 것만으로 어떤 문서 기반 FAQ에도 재활용할 수 있는 구조로 설계한다.

## 3. PRD (Product Requirements Document)

### 3.1 사용자 스토리

| ID | 사용자 스토리 | 우선순위 |
|----|-------------|---------|
| US-01 | 담당자로서, 근로기준법 관련 질문을 입력하면 즉시 답변을 받고 싶다 | 필수 |
| US-02 | 담당자로서, AI가 문서에 없는 내용을 지어내지 않기를 원한다 | 필수 |
| US-03 | 관리자로서, PDF 파일만 교체하면 다른 문서에도 바로 적용하고 싶다 | 필수 |
| US-04 | 사용자로서, 대화 내역이 말풍선 형태로 구분되어 보이기를 원한다 | 필수 |
| US-05 | 관리자로서, API 키가 외부에 노출되지 않기를 원한다 | 필수 |

### 3.2 기능 요구사항

| # | 기능 | 설명 | 우선순위 |
|---|------|------|---------|
| F-01 | PDF 자동 로드 | 서버 시작 시 `docs/` 폴더의 모든 PDF 텍스트를 추출하여 메모리에 저장 | 필수 |
| F-02 | 할루시네이션 방지 | 시스템 프롬프트로 "문서에 없는 내용은 답변 불가" 명시 | 필수 |
| F-03 | 질문-답변 API | `POST /api/chat` — 질문 수신 후 Claude API 호출, 답변 반환 | 필수 |
| F-04 | 말풍선 챗봇 UI | 사용자(우측)/봇(좌측) 말풍선으로 구분된 대화 인터페이스 | 필수 |
| F-05 | PDF 교체 가능 구조 | `docs/` 폴더의 PDF만 바꾸면 다른 문서로 즉시 전환 | 필수 |
| F-06 | API 키 서버 전용 처리 | `ANTHROPIC_API_KEY`를 Vercel 서버리스 함수에서만 사용 | 필수 |
| F-07 | Vercel 배포 | `vercel.json` 설정으로 서버리스 환경 배포 | 필수 |

### 3.3 비기능 요구사항

| 구분 | 요구사항 |
|------|---------|
| 보안 | API 키는 서버(Vercel 환경변수)에서만 처리, 프론트엔드 소스에 절대 미포함 |
| 신뢰성 | 문서 외 답변 시 "문서에서 찾을 수 없습니다" 메시지 반환 |
| 확장성 | `docs/` 폴더 PDF 교체만으로 타 문서 적용 가능 |
| 입력 제한 | 사용자 질문 최대 500자, PDF 컨텍스트 최대 10만 자 |

## 6. 할루시네이션 방지 설계

Claude API 호출 시 아래 시스템 프롬프트를 고정 적용한다:

```
당신은 PDF 문서 기반 노무 FAQ 어시스턴트입니다.
반드시 아래 제공된 문서 내용만을 근거로 답변하세요.
문서에 없는 내용은 절대 추측하거나 지어내지 말고,
"제공된 문서에서 해당 내용을 찾을 수 없습니다."라고 답변하세요.

[문서 내용]
{pdfText}
```

## 7. PDF 교체 가이드 (사용자 관점)

```
1. docs/ 폴더의 기존 PDF 삭제
2. 새 PDF 파일을 docs/ 폴더에 복사
3. 서버 재시작 (또는 Vercel 재배포)
→ 새 문서 기반으로 즉시 동작
```

```
└── vercel.json        # Vercel 서버리스 라우팅 설정
```

## 9. API 설계

### POST /api/chat

**요청**
```json
{ "question": "연차 휴가는 며칠인가요?" }
```

**응답 (문서 내 답변 가능)**
```json
{ "answer": "근로기준법 제60조에 따르면 1년간 80% 이상 출근한 근로자에게는 15일의 유급휴가가 부여됩니다." }
```

**응답 (문서 외 질문)**
```json
{ "answer": "제공된 문서에서 해당 내용을 찾을 수 없습니다." }
```

**에러 응답**
```json
{ "error": "질문을 입력해주세요." }       // 400 — 빈 질문
{ "error": "서버 오류가 발생했습니다." }  // 500 — API 호출 실패
```

## 10. 보안 요구사항

- `ANTHROPIC_API_KEY`는 `server.js`에서 `process.env`로만 접근
- 프론트엔드(`public/`) 코드에 API 키 절대 미포함
- `.env` 파일은 Git에 포함하지 않음 (`.gitignore` 적용)
- 배포 시 Vercel 대시보드 환경변수에 키 설정

## 11. 제약 조건

- PDF는 `docs/` 폴더에 사전 배치 (런타임 업로드 기능 없음 — MVP 범위 외)
- 여러 PDF가 있을 경우 모든 텍스트를 합쳐서 컨텍스트로 전달
- PDF 텍스트는 최대 10만 자로 제한 (Claude API 컨텍스트 한도 고려)
- 사용자 질문 최대 500자
