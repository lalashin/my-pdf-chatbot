# 2025-05-07 강의 실습 정리 — PDF 챗봇 API 전환기

## Q1. OpenAI key로 gpt-4o-mini 챗봇을 만들었는데, 허깅페이스에서 대체할 모델이 있을까?

### 답변

허깅페이스에서 GPT-4o-mini를 대체할 수 있는 모델 3가지:

| 모델 | 크기 | 특징 | 한국어 지원 |
|------|------|------|-------------|
| Mistral-7B-Instruct-v0.3 | 7B | 가장 안정적, 영어 최강 | 보통 |
| Qwen2.5-7B-Instruct | 7B | 한국어 강력 지원 | 우수 |
| HuggingFaceH4/zephyr-7b-beta | 7B | instruction following 특화 | 보통 |

한국어 PDF 챗봇이라면 **Qwen2.5-7B-Instruct** 추천.

허깅페이스는 OpenAI 호환 API 엔드포인트를 제공하므로 `baseURL`과 API 키만 바꾸면 나머지 코드는 그대로 사용 가능하다.

```js
// 기존 (OpenAI)
const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

// 변경 (허깅페이스)
const openai = new OpenAI({
  apiKey: process.env.HUGGINGFACE_API_KEY,
  baseURL: 'https://router.huggingface.co/hf-inference/v1',
});
```

## Q2. Inference API 발급해서 여러 모델 변경해서 사용 가능한가?

### 답변

API 키는 1개만 있으면 되고, **모델명(`model`)만 바꾸면** 다른 모델로 전환 가능하다.

```js
const completion = await openai.chat.completions.create({
  model: 'Qwen/Qwen2.5-7B-Instruct',  // ← 이 부분만 변경
  ...
});
```

`.env`에서 모델명을 관리하면 편리하다:

```
HUGGINGFACE_API_KEY=hf_xxxxxxxxxx
HF_MODEL=Qwen/Qwen2.5-7B-Instruct
```

#### 무료 vs 유료 차이

| 구분 | 무료 (Serverless) | 유료 (Dedicated) |
|------|------------------|-----------------|
| 속도 | 느림, 콜드스타트 있음 | 빠름 |
| 제한 | 분당 요청 수 제한 | 없음 |
| 비용 | 무료 | 시간당 과금 |
| 모델 | 인기 모델만 | 모든 모델 |

실습용이면 무료로 충분하다.

## Q3. baseURL은 공통으로 사용하는가?

### 답변

**baseURL은 고정**이고 `model`만 바꾸면 된다.

```
baseURL: 'https://router.huggingface.co/hf-inference/v1'
                   ↑ 허깅페이스 라우터 서버 (고정)

model: 'Qwen/Qwen2.5-7B-Instruct'
         ↑ 이것만 바꾸면 다른 모델로 전환
```

| 항목 | 변경 여부 |
|------|----------|
| baseURL | 고정 (항상 동일) |
| apiKey | 고정 (내 HF 토큰) |
| model | 변경 가능 (모델명만 바꾸면 됨) |

## Q4~Q8. 실제 허깅페이스 연동 시도 및 오류 과정

### 시도 1 — Qwen/Qwen2.5-7B-Instruct + hf-inference
```
오류: 400 "Model not supported by provider hf-inference"
```
→ `hf-inference` provider가 해당 모델을 지원하지 않음.

### 시도 2 — meta-llama/Llama-3.1-8B-Instruct + hf-inference
```
오류: 400 "Model not supported by provider hf-inference"
```
→ 동일한 문제.

### 시도 3 — baseURL을 `novita`로 변경
```
오류: 400 "Model not supported by provider novita"
```

### 시도 4 — mistralai/Mistral-7B-Instruct-v0.2 + together
```
오류: 410 "The requested model is deprecated and no longer supported by provider together"
```

### 핵심 교훈

> 허깅페이스 라우터는 모델마다 지원하는 provider가 다르다.  
> 맞는 조합(provider + model)을 찾는 게 쉽지 않고, deprecated도 잦다.

모델 페이지 확인 방법:
1. `https://huggingface.co/{모델명}` 접속
2. 오른쪽 **Deploy** 버튼 클릭
3. **Inference API (serverless)** 클릭
4. `Provider: together` 같은 값 확인 → 해당 값을 baseURL에 사용

## Q9. 허깅페이스 말고 다른 무료 API로 전환 — Groq란?

### Groq 개념 설명

| | 비유 |
|--|------|
| 허깅페이스 | 도서관 (책이 엄청 많지만 대출이 느릴 수 있음) |
| Groq | 편의점 (인기 책만 골라서 빠르게 제공) |

Groq는 허깅페이스와 **별개의 회사**다. 허깅페이스에 올라온 인기 모델을 자기네 서버(LPU 칩)에서 빠르게 서비스한다.

| 서비스 | 무료 한도 | 특징 |
|--------|----------|------|
| Groq | 하루 14,400 요청 | 매우 빠름, Llama/Mixtral 지원 |
| Google Gemini | 하루 1,500 요청 | 한국어 우수 |
| Cohere | 월 1,000 요청 | 문서 검색 특화 |

Groq는 OpenAI 호환 API라서 **baseURL만 바꾸면** 코드 거의 동일하다:
```js
baseURL: 'https://api.groq.com/openai/v1'
model: 'llama-3.1-8b-instant'
```

## Q10. Groq 전환 후 토큰 한도 오류

### 오류 내용
```
413 Request too large for model `llama-3.1-8b-instant`
Limit 6000, Requested 9745
```

### 원인 및 해결

Groq 무료 플랜은 **분당 6,000 토큰** 한도.

```
PDF 컨텍스트 토큰 + 질문 토큰 + 답변 토큰 ≤ 6,000
```

→ `CONTEXT_FULL_DOC_THRESHOLD`와 `RETRIEVAL_CONTEXT_MAX_CHARS` 값을 줄여서 해결.

## Q11. 답변 품질 개선 방법

### 현재 문제
- Groq 무료 플랜 분당 6,000 토큰 제한
- PDF 컨텍스트가 크면 답변 공간이 부족해 중간에 잘림

### 개선 방법 3가지

**1. 더 큰 모델로 변경**
```
llama-3.1-8b-instant → llama3-70b-8192
```
70B 모델이라 답변 품질이 훨씬 좋음. 단, 토큰 한도는 동일.

**2. 토큰 한도가 더 넉넉한 모델 사용 (추천)**

| 모델 | 분당 토큰(TPM) |
|------|---------------|
| llama-3.1-8b-instant | 6,000 |
| llama-3.3-70b-versatile | 6,000 |
| gemma2-9b-it | 15,000 |

`gemma2-9b-it`이 한도가 2.5배 많아서 컨텍스트도 넓히고 답변도 길게 가능.

**3. OpenAI로 복귀 (유료)**

원래 gpt-4o-mini가 품질·속도·안정성 모두 최고. 소액 충전($5)으로 오래 사용 가능.

## 허깅페이스 vs Groq 최종 비교

| | 허깅페이스 | Groq |
|--|-----------|------|
| 설정 난이도 | 높음 (provider+모델 조합 맞춰야 함) | 낮음 (키 하나로 바로 됨) |

## Q12. SambaNova란? Groq와 비교하면?

### SambaNova 개념

자체 AI 칩(RDU)으로 오픈소스 LLM을 빠르게 서빙하는 서비스. Groq와 유사한 포지셔닝이지만 **토큰 한도가 훨씬 크고 대형 모델을 무료로 사용 가능**하다.

| 항목 | Groq | SambaNova |
|------|------|-----------|
| 무료 TPM 한도 | 6,000 | 300,000~1,000,000 |
| 최대 모델 크기 | 70B 수준 | 405B, Llama 4 |
| 한국어 | 보통 | Qwen 선택 가능 → 우수 |
| 속도 | 업계 최고 | 약간 느림 |
| 안정성 | 높음 | 높음 |

**결론**: 속도 우선이면 Groq, 토큰 한도 + 큰 모델이 필요하면 SambaNova.

### SambaNova API 연동 방법

```js
// server.js
const openai = new OpenAI({
  apiKey: process.env.SAMBANOVA_API_KEY,
  baseURL: 'https://api.sambanova.ai/v1',
});
```

```
# .env
SAMBANOVA_API_KEY=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
HF_MODEL=Meta-Llama-3.3-70B-Instruct
```

### 가입 시 주의사항
- `cloud.sambanova.ai` 에서 무료 가입
- **전화번호 인증 필수** (한국 번호 +82 사용 가능)
- 신용카드 불필요

## Q15. 마크다운이 화면에 `**굵게**` 텍스트로 그대로 출력되는 문제

### 원인

`public/app.js`에서 `msg.textContent = text` 로 출력하면 마크다운 기호가 그대로 표시됨.

### 해결 — 마크다운 렌더링 함수 추가

외부 라이브러리 없이 `public/app.js`에 변환 함수 직접 구현.

```js
function markdownToHtml(text) {
  return text
    .replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;') // XSS 방지
    .replace(/\*\*(.+?)\*\*/g, '<strong>$1</strong>')  // **굵게**
    .replace(/^[\*•]\s+(.+)$/gm, '<li>$1</li>')        // 목록 항목
    .replace(/(<li>[\s\S]+?<\/li>)(?=\s*(?!<li>))/g, '<ul>$1</ul>') // ul 감싸기
    .replace(/\n{2,}/g, '</p><p>')  // 빈 줄 → 단락
    .replace(/\n/g, '<br>')         // 줄바꿈
    .replace(/^/, '<p>').replace(/$/, '</p>');
}

// bot 답변만 마크다운 렌더링 적용
if (type === 'bot-msg') {
  msg.innerHTML = markdownToHtml(text);
} else {
  msg.textContent = text;  // 사용자 메시지는 텍스트 그대로
}
```

### 핵심 포인트
- `textContent` → 텍스트 그대로 출력 (마크다운 미렌더링)
- `innerHTML` → HTML로 파싱해서 출력 (마크다운 렌더링 가능)
- XSS 방지를 위해 HTML 특수문자(`&`, `<`, `>`) 이스케이프 먼저 처리
