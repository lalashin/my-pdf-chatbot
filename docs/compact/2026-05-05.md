# 세션 요약 — 2026-05-05

## 프로젝트 개요

PDF 문서를 읽고 질문에 답변하는 챗봇 서비스 구축.

- **프로젝트명**: PDF 기반 노무 FAQ 챗봇
- **AI 모델**: claude-haiku-4-5 (Anthropic Claude API)
- **배포 환경**: Vercel
- **GitHub**: https://github.com/lalashin/my-pdf-chatbot.git (main 브랜치, 최신 커밋: bd8e2d1)

---

## 기술 스택

| 구분 | 내용 |
|------|------|

## 주요 구현 내용

### server.js
- `docs/` 폴더 PDF 전체 로드, 최대 10만 자 제한
- 할루시네이션 방지 시스템 프롬프트 (문서 외 내용 답변 금지 → "제공된 문서에서 해당 내용을 찾을 수 없습니다.")
- `POST /api/chat` 엔드포인트 (빈값/500자 초과 검증)

### public/
- `index.html`: 말풍선 챗봇 UI, `#chat-box` + `#input-area`, `maxlength="500"`
- `style.css`: `.user-msg`(파란/우측), `.bot-msg`(회색/좌측), `.loading-msg`(점멸)
- `app.js`: `fetch POST /api/chat`, 말풍선 렌더링, Enter 키 전송, 자동 스크롤, 네트워크 오류 처리

### vercel.json
- `@vercel/node` 빌드, 모든 요청 `server.js`로 라우팅

## 확인된 정상 동작

- PDF 텍스트 로드: 근로기준법 47,200자 추출 성공
- UI 말풍선 렌더링: 정상 동작 (스크린샷 확인)
- API 키 환경변수 로드: 정상 (`process.env`로만 접근, 프론트 미노출)
- 포트 3000 충돌(EADDRINUSE) → 기존 프로세스 종료 후 해결

## 미해결 문제

| 문제 | 원인 | 상태 |
|------|------|------|
| "서버 오류가 발생했습니다." | Anthropic 크레딧 부족 (`credit balance is too low`) | ❌ 미해결 |
| 결제 버튼 미작동 | PC(Chrome/Edge/Firefox) + 모바일 모두 버튼 클릭 불가 | ❌ 미해결 |

- API 키 자체는 유효 (인증 오류 아님)
- 이전에 결제된 이력 있음 → Anthropic 콘솔 버그로 추정
- **권장 조치**: support.anthropic.com 문의

## 다음 단계 (크레딧 해결 후)

1. `node server.js` 로 서버 재시작
2. `http://localhost:3000` 에서 질문 테스트
   - 문서 내 질문: "연차 휴가는 며칠인가요?"
   - 문서 외 질문: "오늘 날씨는?" → "제공된 문서에서 해당 내용을 찾을 수 없습니다." 확인
3. 테스트 완료 후 Vercel 배포: `vercel --prod`
