## 주요 구현 내용

### server.js
- `docs/` 폴더 PDF 전체 로드, 최대 10만 자 제한
- 할루시네이션 방지 시스템 프롬프트 (문서 외 내용 답변 금지 → "제공된 문서에서 해당 내용을 찾을 수 없습니다.")
- `POST /api/chat` 엔드포인트 (빈값/500자 초과 검증)

### public/
- `index.html`: 말풍선 챗봇 UI, `#chat-box` + `#input-area`, `maxlength="500"`
- `style.css`: `.user-msg`(파란/우측), `.bot-msg`(회색/좌측), `.loading-msg`(점멸)
- `app.js`: `fetch POST /api/chat`, 말풍선 렌더링, Enter 키 전송, 자동 스크롤, 네트워크 오류 처리

### vercel.json
- `@vercel/node` 빌드, 모든 요청 `server.js`로 라우팅

## 2차 세션 추가 작업 — 2026-05-05 (오후)

### 1. Anthropic → OpenAI 전환 및 최신 API 버전 수정

크레딧 문제로 Anthropic API 대신 OpenAI API로 전환 완료.

| 파일 | 변경 내용 |
|------|-----------|
| `package.json` | `@anthropic-ai/sdk` 제거, `openai ^4.104.0` 추가, `express ^4.22.0` → `^5.1.0` |
| `server.js` | `AnthropicClient` → `OpenAI` 클라이언트, `max_completion_tokens` → `max_tokens` |

**`max_completion_tokens` → `max_tokens` 수정 이유**:  
`max_completion_tokens`는 o1/o3 추론 모델 전용 파라미터. `gpt-4o-mini`는 `max_tokens` 사용 (context7 공식 문서로 확인)

**Express 버전 업그레이드 이유**:  
Express 5.1.0이 2025년 npm 기본값으로 승격됨. 기존 코드(async 핸들러, `res.json()`)는 이미 v5 호환 구조.
